# v1.6.1 — Backend merge

تم دمج ملف `index.js` الوارد من المطور الآخر داخل `server/index.js` مع الحفاظ على نسخة v1.6 Final Optimized.

## الإضافات المدمجة
- إدارة مستخدمي لوحة التحكم للـ Owner عبر API.
- تغيير كلمة مرور المستخدم الحالي عبر API.
- إعادة تعيين كلمة مرور مستخدم إدارة بواسطة الـ Owner عبر API.
- تقرير شامل جديد: `GET /api/reports/full` مع فترة من/إلى.
- `GET /api/auth/me` يعيد معرف المستخدم أيضًا.
- بيانات `ADMIN_USERNAME` و `ADMIN_PASSWORD` أصبحت Bootstrap لإنشاء الحساب أول مرة، وليست إعادة تعيين تلقائية لكلمة المرور عند كل Cold Start.

## ملاحظات
- لم يتم تغيير MongoDB/Cloudinary/POS/الصور/WebP أو منطق المنيو والطلبات في v1.6.
- لا توجد Environment Variables جديدة مطلوبة لهذا الدمج.
- واجهة الإدارة الحالية تظل كما هي؛ الـ APIs الجديدة متاحة للاستخدام أو لإضافة شاشة مستخدمين لاحقًا.
