# حالة مشروع مطبخ ماما حنان

## مكتمل
- الهوية بالكامل باسم مطبخ ماما حنان.
- توزيع اللوجو الأفقي، البادج، الأيقونة والهيرو على الموقع.
- SEO وOpen Graph وPWA icons.
- الرئيسية والمنيو والجاليري والخدمات.
- سلة وCheckout وتسجيل الطلب في MongoDB ثم فتح واتساب.
- MongoDB Atlas database باسم `mama_hanan_kitchen`.
- Seed تلقائي لأول تشغيل لقاعدة البيانات الفارغة.
- Cloudinary folders منفصلة باسم `mama-hanan-kitchen`.
- لوحة Admin للوجبات، الأقسام، الصور، الطلبات والإعدادات.
- رفع Hero واللوجو من لوحة الإعدادات.
- تغيير ADMIN_PASSWORD من Vercel يحدّث كلمة مرور المدير بعد Redeploy.
- Backup / Restore.
- فصل LocalStorage وService Worker cache بالاسم الجديد.
- Mobile-first RTL.

## المطلوب منك فقط بعد الرفع
- إدخال رقم واتساب والهاتف والعنوان والمواعيد والسوشيال من Admin.
- استبدال صور الوجبات التجريبية بصور الأكل الحقيقية من Admin.
- مراجعة الأسعار والأحجام.

## تحديث v1.4.0
- إصلاح حفظ الوجبات ورسائل Server error العامة، ومعالجة تكرار slug تلقائيًا.
- إدارة كاملة للخدمات من لوحة التحكم وربط صفحة الخدمات بـ MongoDB.
- مرونة أكبر للصور: معاينة، تغيير، إزالة، WebP تلقائي، وتنظيف صور Cloudinary القديمة المرتبطة عند الاستبدال/الحذف.
- صور إضافية متعددة لكل وجبة وعرضها في نافذة تفاصيل المنتج.
- ترتيب يدوي للوجبات، وتحسين تجربة النوافذ الطويلة في الإدارة.
- Backup/Restore يشمل الخدمات.
